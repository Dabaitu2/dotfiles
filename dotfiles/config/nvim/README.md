# Neovim 配置 - ToggleTerm 终端管理

本配置基于 toggleterm.nvim 插件，提供了强大的多终端管理功能。

## 🚀 功能特性

- **多终端支持**：可同时打开多个不同类型的终端
- **智能切换**：支持列表选择和循环切换
- **多种方向**：浮动、水平、垂直三种终端方向
- **Telescope 集成**：美观的终端列表界面
- **自动编号**：新终端自动编号管理
- **快速操作**：丰富的快捷键支持

## ⌨️ 快捷键一览

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `<leader>t` | 切换默认终端 | 水平方向终端 |
| `<C-\>` | 全局终端开关 | 系统级快捷键 |

| `<leader>tc` | 水平终端 | 底部水平分割 |
| `<leader>tg` | LazyGit | Git 图形界面 |

## 📋 使用示例

### 1. 创建多个终端
```vim
" 创建几个不同类型的终端
<leader>tn    " 新建浮动终端
<leader>th    " 新建水平终端
<leader>tv    " 新建垂直终端
```

### 2. 终端切换
```vim
" 查看所有终端并选择
<leader>tl    " 打开终端列表
<leader>ts    " 打开终端选择器

" 快速循环切换
<leader>tc    " 切换到下一个终端
```

### 3. 在 Telescope 列表中
当使用 `<leader>tl` 或 `<leader>ts` 打开终端列表时：
- **回车** - 切换到选中的终端
- **`<C-d>`** - 关闭选中的终端
- **`<C-c>`** - 取消选择

### 4. 终端内操作
在终端内部时：
- **`<Esc>`** - 退出插入模式到普通模式
- **`<A-hjkl>`** - 在窗口间跳转（与普通窗口相同）
- **`<leader>tc`** - 循环切换到下一个终端

## 🎯 实际工作流示例

### 场景：同时进行多个任务
```vim
" 1. 打开代码编辑
nvim myproject/

" 2. 创建终端运行开发服务器
<leader>tn
npm run dev

" 3. 创建另一个终端运行测试
<leader>th
npm test

" 4. 创建第三个终端进行 Git 操作
<leader>tv
git status

" 5. 在终端间切换查看状态
<leader>tc    " 循环查看各个终端
" 或者
<leader>tl    " 从列表中选择
```

### 场景：快速查看和关闭
```vim
" 查看所有打开的终端
<leader>tl

" 选择要关闭的终端，按 <C-d> 关闭
" 或者使用循环切换找到要关闭的终端
<leader>tc
```

## 🔧 配置说明

### 文件位置
- 主配置：`lua/plugin-config/toggleterm.lua`
- 快捷键配置：`lua/keybindings.lua`

### 主要功能函数
- `create_new_terminal()` - 创建新终端
- `get_open_terminals()` - 获取所有打开的终端
- `show_terminal_picker()` - 显示终端选择器
- `cycle_terminals()` - 循环切换终端
- `switch_to_terminal()` - 切换到指定终端
- `close_terminal()` - 关闭指定终端

### 自定义选项
创建终端时可以指定：
- `direction` - 方向：'float', 'horizontal', 'vertical'
- `close_on_exit` - 退出时是否自动关闭
- 其他 toggleterm 支持的选项

## 💡 提示与技巧

1. **终端命名**：新终端会自动编号为 "Terminal 1", "Terminal 2" 等
2. **方向识别**：终端列表中会显示每个终端的方向类型
3. **智能循环**：循环切换会自动跳过已关闭的终端
4. **快速关闭**：在终端列表中可以直接关闭不需要的终端
5. **后备方案**：如果 Telescope 未安装，会自动使用文本列表

## 🔍 故障排除

### Telescope 未安装
如果看到 "Telescope 未安装" 的提示，系统会自动切换到文本列表模式，你仍然可以使用数字选择终端。

### 终端无法切换
确保终端已经正确打开，使用 `<leader>tl` 查看当前打开的终端列表。

### 快捷键冲突
如果快捷键与其他插件冲突，可以在 `lua/keybindings.lua` 中修改相应的映射。
